# Blind Chess preparation and clear timing

Status: ready-for-agent

## Parent

https://github.com/zwka/offline-chess/issues/3

## What to build

Apply the approved identity to Blind Chess and let the player choose a drill, read untimed instructions, and explicitly Start before answering.

## Acceptance criteria

- [ ] Apply the shared logo/brand link, richer Ink & Brass, and heading/control typography on phone and desktop while retaining appropriate drill-specific layouts.
- [ ] Retain all six drills, completed Attempt history, and personal bests.
- [ ] Selecting a drill presents instructions and an explicit Start action; preparation consumes no round time.
- [ ] Explain and retain the existing 60-second clock start on the first answer, not on drill selection or Start.
- [ ] Keep prompts, answer targets, results, and error feedback legible and accessible in both Themes; preserve production functionality rather than substituting the prototype.
- [ ] Add browser coverage for drill selection, preparation, Start, first-answer timing, and access to history; use controlled clocks and representative phone/desktop checks.
