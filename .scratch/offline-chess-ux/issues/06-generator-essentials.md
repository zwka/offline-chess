## Parent

## What to build

Make common Puzzle Set generation straightforward on phone and desktop while retaining advanced control and an obvious path from output to solving or export.

## Acceptance criteria

- [ ] Keep rating, Tactic Themes, puzzle count, necessary naming, and generation actions readily accessible.
- [ ] Put seed and all/any matching in expandable Advanced options; toggling disclosure must not reset values or alter selection semantics/reproducibility.
- [ ] Provide an obvious completion cue and reachable generated output, Do Puzzles, and export even after a long phone filter form.
- [ ] Apply shared branding, richer Ink & Brass, typography, accessible controls, and clear progress/error feedback in both Themes without implying unsaved state is durable.
- [ ] Preserve existing index selection, deterministic generation, JSON export, nonempty naming requirements, and direct Handoff behavior.
- [ ] Browser-test generation with small deterministic fixtures, advanced setting retention, mobile output reachability, export, and repeated Handoff deduplication/active-Run reuse.
